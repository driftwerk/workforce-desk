# Chrome Web Store listing: Desk

**Name:** Desk

**Summary** (132 characters at most):
Lets the Desk app on your computer use Chrome for you, signed in as you, in a window of its own.

**Category:** Productivity → Tools

**Language:** English

**Description:**

Desk is an app on your computer where AI agents work with you. This extension lets Desk use your own Chrome for them: it opens pages, reads them and, as you allow, clicks and types there, signed in to the sites you already use.

- **A window of its own.** Desk works in a Chrome window and a tab group named "Desk", never in your other tabs or windows.
- **You decide.** Desk asks you before an agent uses your Chrome in a conversation, before it opens each new site, and before it clicks or types on a page (unless you let an agent act fully). The sites it may never go to are yours to list.
- **Stop at any time.** The toolbar button shows what Desk is doing and has a Stop button. Desk's own app has one too.
- **Only Desk on this computer.** The extension talks only to the Desk app on this same computer, through Chrome's native messaging. No server of ours sees your pages.
- **Confirmed once.** The first time, Desk shows a code and asks you to confirm that this Chrome is yours. The extension's popup shows the same code.

You need the Desk app installed on this computer: https://github.com/driftwerk/workforce-desk

**Single purpose** (the dashboard's "Single purpose description"):
Lets the Desk app on this computer use Chrome for the person, in a window of its own, to open, read and act on web pages they ask Desk's agents to work on.
