↑ edits your last message

In an empty composer, ↑ opens your last message for editing. You can also choose Edit from its hover menu.

  • Saving replaces the message, which then reads "(edited)". Desk's old reply is set aside (dimmed here) and the agent answers again.
  • If that reply took actions, the edit box lists them first. They can't be undone, so the agent is told they happened rather than pretending otherwise.
  • Only your latest message, and only once the agent has finished replying. Edit an earlier one and later replies would no longer fit.

Delete your messages

Hover a message you sent, then Delete. You confirm in place, with no pop-up.

  • It's removed from the chat and from the agent's history, so it can't come back in a later turn.
  • Anything the agent saved to memory from it is listed by name, with "also forget" ticked.
  • The agent's replies stay, marked "answered a deleted message", so the chat still reads correctly.
  • The agent's own messages can't be deleted. You can only hide them, so nothing is lost by accident.

Search the chat

⌘F in a chat searches its whole history, including what isn't loaded yet.

  • Matches are listed on the right, newest first. ↑ ↓ or Enter steps through them.
  • Choosing a match loads the chat around it and highlights it in place, with the conversation either side.
  • Filters to come if wanted: "from me", "from the agent", a date.
  • The search runs on the hub, so it also covers chats from another device.

Threads in a DM

Reply in thread on any message opens it beside the chat. The main chat keeps moving, and the message shows "4 replies".

  • In a thread the agent sees the message it started from, the thread, and the chat up to that point. Other threads stay out.
  • A thread runs its own turn, so the agent can work on two things at once, as it does here: drafting in the thread while promoting #509 in the main chat.
  • "Also send to the chat" posts a reply in both places, like Slack.
  • Memory is shared: what the agent learns in a thread it knows everywhere.
  • Threads in a Slack DM map to these one to one.

Needs a hub change: replies in a DM carry the id of the thread they're in.

Shortcuts: ↑ edit last · End latest · ⌘F search · T on a hovered message, reply in thread
